# ClipDuel guides

Static user guides for ClipDuel, served with GitHub Pages.

- `index.html`: landing page
- `first-run.html`: Make clips, the first-run guide
- `text-to-video.html`: Make videos, the text-to-video guide
- `animate.html`: Animate (Labs), its four modes and what each needs

Plain HTML with no build step. Screens are simplified mockups of the app: three tabs (Make clips, Make videos, Schedule) plus Animate (Labs) when the server enables it.
