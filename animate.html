BEFORE YOU START · labs

Turn the tab on

Animate calls a paid video service, so it stays off until you turn it on in the server's .env file.

  • ANIMATE_ENABLED=true adds the Animate tab. While it's off, the tab doesn't appear and the server doesn't set up anything for it.
  • INFSH_API_KEY is your inference.sh key. Install its CLI with brew install inference-sh/tap/belt. Without a key, the tab shows but can't run: the three generated modes are greyed out in the Mode menu, and Video → talk/action shows a message naming the missing key.
  • With a key set, the server checks at startup that the CLI runs and that the configured models are ones it knows. If either check fails, the server won't start, and it names the setting to fix.
  • OpenAI is needed only for a talk segment's TTS voice or captions. The other three modes never use it.

Restart pnpm dev after editing .env. The Mode menu starts on Video → talk/action the first time. After that, your browser remembers the mode you used last.

MODE 1 · IMAGE TO VIDEO

Animate one photo

Drop in a photo, say how it should move, and get one short clip that starts on your photo.

  • PNG, JPEG, or WebP, up to 10 MB, with the shorter edge at least 300 px. Export iPhone HEIC photos as JPEG first.
  • Write a prompt of up to 500 characters, or tap an idea chip to add one.
  • Length is 4–10 whole seconds (5 by default).
  • The clip keeps the photo's shape: a portrait photo makes a portrait clip, and a landscape photo makes a landscape clip.
  • Generate sound is on by default and doesn't change the price.

The estimate is a ceiling, so the real charge is usually lower. In Make videos, the References card has a Have a photo? Animate it → link that opens this mode.

MODE 2 · TEXT TO VIDEO

Describe a shot

No image needed. Describe the shot and the model makes it from scratch.

  • Choose a ratio: 9:16 (the default), 16:9, or 1:1.
  • Length is 4–10 seconds.
  • It costs more per second than the image modes, because the model starts from nothing.

This makes one short shot with no narration or captions. To turn a script into a narrated video, use Make videos.

MODE 3 · AI TRANSITION

Move from one image to another

Give a start image and an end image. The clip opens on the first and lands on the second.

  • The two images must be different and the same shape (aspect ratios within 2%). If they aren't, the form tells you before you submit. Otherwise the model would silently crop your end image.
  • Swap start and end flips them.
  • The prompt is optional. Left empty, it uses a smooth cinematic transition.
  • Length is 4–8 seconds.
MODE 4 · VIDEO → TALK/ACTION

Make your subject talk or act

Film your cat, then make it answer back. Upload a video, mark up to three moments, and the app cuts to an animated version of that frame, then back to your footage.

  • Upload an MP4, MOV, WebM, or MKV, then + Add segment (up to 3). Set each cut time and check the frame preview beside it.
  • talk: the subject lip-syncs a line. Use a TTS voice (choose a voice, type up to 200 characters) or Your recording (an audio file up to 12 s). Captions use one of the four caption styles, or none, and show only while it speaks.
  • action: describe what it does, for 4–10 seconds. Action segments are silent.
  • After each segment: Resume where it cut adds the animation, so the video gets longer. Skip ahead to… replaces that stretch of your footage instead.

TTS voices and captions need OPENAI_API_KEY. A recorded voice with captions off needs no OpenAI key at all. Talk costs about $0.12 and action about $0.10 per second of animation.

EVERY MODE · THE RESULT

Wait, then download

Each job gets a card under the form. A generated clip usually takes two to three minutes, and a talk/action job takes longer with more segments.

  • The three generated modes go Queued → Generating → Finishing. Video → talk/action goes preparing → generating → splicing.
  • You can leave the page. If the app restarts, the job picks up where it stopped. A clip that was already generated isn't paid for again.
  • When it's done, the card shows a player and a Download link. Animate clips aren't part of blind picks or the Schedule queue, so download one and post it yourself.
  • Submitting the exact same job again costs nothing, because every paid call is cached.

If you asked for sound but the model sent back none, the card says the clip is silent.
